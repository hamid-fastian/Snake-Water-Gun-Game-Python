# 🐍💧🔫 Snake Water Gun Game (Python)

## 📌 Overview

A console-based Snake Water Gun Game developed in Python. The game allows the player to compete against the computer by choosing **Snake**, **Water**, or **Gun**. The computer randomly selects its move, and the winner is decided according to the game rules.

This project was built to strengthen Python fundamentals through a practical application. It demonstrates problem-solving skills, randomization, score tracking, clean game logic, and an interactive console interface.

---

## ✨ Features

### 🎮 Gameplay

- Random computer choice
- Interactive player input
- Multiple game rounds
- Round counter
- Live score tracking
- Player vs Computer gameplay
- Win, Lose, and Draw detection
- Emoji-based game interface
- Exit option
- Final game summary

## 🎯 Game Rules

- 🐍 Snake drinks Water.
- 💧 Water damages Gun.
- 🔫 Gun defeats Snake.
- Same choices result in a Draw.

---

## 🎮 How to Play

1. Run the program.
2. Choose one of the following options:
   - **1** → Snake 🐍
   - **2** → Water 💧
   - **3** → Gun 🔫
   - **4** → Exit
3. The computer randomly selects its move.
4. The round winner is displayed.
5. Scores are updated after every round.
6. Continue playing until you choose to exit.
7. The final scoreboard announces the winner.
